## Задача 1 — Веб-калькулятор дозировки

**Тема:** расчёт дозы лекарственного препарата по массе тела пациента.

**Как запустить:** открыть `task1-dosage-calculator/index.html` в браузере (сервер не нужен).

**Нетривиальная логика:**
- Дозирование зависит от возрастной группы (взрослый / ребёнок / младенец) и массы тела
- Применяется коэффициент коррекции при нарушении функции почек (4 уровня)
- Разовая и суточная дозы ограничены максимально допустимыми значениями (кэппинг)
- При противопоказаниях — явное предупреждение вместо расчёта

**Файловая структура:**
```
index.html      разметка
styles.css      стили
drugs.js        справочник препаратов с дозировками
calculator.js   чистая функция расчёта (без DOM)
app.js          UI-логика (форма, валидация, рендер результата)
```

**Описание работы с Claude Code:**

Начал с промпта: *«Создай веб-калькулятор дозировки лекарств: выбор препарата, ввод веса, возрастная группа, кратность. Разовую и суточную дозы считать через mg/kg с кэппингом по maxSingle и maxDaily. Разбить на 4 файла: HTML, CSS, drugs.js (данные), calculator.js (логика), app.js (UI)»*. AI сразу сгенерировал корректную структуру с разделением слоёв. Второй промпт добавил коррекцию при почечной недостаточности (`renalFactor`) и обработку противопоказаний для возрастных групп. Правил руками: переименовал CSS-классы для единообразия, убрал избыточные комментарии, скорректировал порядок кэппинга (сначала single, потом пересчёт daily от него).

## Задача 2 — Python + Docker (курсы ЦБ РФ)

**API:** `https://www.cbr-xml-daily.ru/daily_json.js` — публичный, без авторизации.

**Что делает:**
- Получает актуальные курсы 10 ключевых валют
- Считает изменение за день (абсолютное и в %)
- Выводит форматированную таблицу в консоль
- Сохраняет результат в `cbr_rates.csv`

**Запуск:**
```bash
# Локально
pip install -r requirements.txt
python main.py

# Docker
docker build -t cbr-rates task2-cbr-rates/
docker run --rm cbr-rates
```
