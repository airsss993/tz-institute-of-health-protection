# Task 3 — Apps Script: Курсы ЦБ РФ в Google Таблице

## Что делает скрипт

- Запрашивает курсы валют через API `cbr-xml-daily.ru`
- Рассчитывает курс за 1 единицу и изменение относительно предыдущего дня
- Записывает данные в лист «Курсы» с подсветкой роста/падения
- Обновляет статусную ячейку (успех / ошибка)

## Триггеры

| Способ | Как работает |
|--------|-------------|
| **Меню «Валюты ЦБ РФ → Обновить курсы»** | Ручной запуск в один клик |
| **Ежедневный таймер** | Устанавливается через «Установить ежедневный триггер» — запускается в 9:00 каждый день |

## Как подключить

1. Откройте Google Таблицу
2. Расширения → Apps Script
3. Вставьте содержимое `Code.gs`, сохраните
4. Обновите страницу таблицы — появится меню **«Валюты ЦБ РФ»**
5. Нажмите «Обновить курсы» (при первом запуске запросит разрешения)

## Структура листа «Курсы»

| Строка | Содержимое |
|--------|-----------|
| 1 | Заголовки столбцов |
| 2 | Статус последнего обновления |
| 3+ | Данные по валютам |

Столбцы: Дата курса / Код / Название / Номинал / Курс (руб.) / Курс вчера / Изм. (руб.) / Изм. (%)
