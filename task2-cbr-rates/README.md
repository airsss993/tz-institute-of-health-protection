# Task 2 — CBR Exchange Rates

Скрипт запрашивает официальные курсы валют ЦБ РФ, считает изменение за день и сохраняет CSV.

## Запуск локально

```bash
pip install -r requirements.txt
python main.py
```

## Запуск через Docker

```bash
docker build -t cbr-rates .
docker run --rm cbr-rates
```

Если нужно получить CSV из контейнера:

```bash
docker run --rm -v "$(pwd)/output:/app" cbr-rates
# файл появится в ./output/cbr_rates.csv
```
